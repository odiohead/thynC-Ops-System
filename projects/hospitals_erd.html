디바이스 원장 — device_units / hospital_devices / hospital_wards / hospital_device_events / hospital_device_import_batches 시리얼 개체

2026-09-02 재정의 (projects/hospital_device_registry_design.md) — 구 hospital_devices(병원×모델 수량 N:M, 8월 수동 센서스)는 폐기(마이그 내 hospital_devices_qty_backup_202609 백업 후 DROP)되고, 같은 테이블 이름이 시리얼 배치 프로젝션으로 승계됐다. 3층 구조: device_info(모델 마스터) → device_units(시리얼 정체성) → hospital_devices(병원 배치 상태, 유닛당 0..1행). 이력은 append 이벤트(hospital_device_events)가 단일 소스이고 배치 행은 fold 파생값. API 공개 device id = device_units.id.
