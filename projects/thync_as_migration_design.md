## 3. 확정 규칙 (2026-09-03 사용자 결정)

1. **완료 판정 = X열** (V열 발송일 아님 — 방문교체는 발송일 없이 완료됨. 실측: 완료 3,352행 중 V빈값 42행뿐)
   - X=완료: W에 시리얼 있으면 F=W→**수리 반환**(AS 접수(A일)→해제(V일)) / F≠W→**교체**(AS 접수→replaceDevice(V일), 분실 행은 사유 LOST)
   - X=완료 & W 없음(40행/162대): **동일기기 수리 반환으로 간주** (방문교체 — 한계로 기록)
   - X=미완료(111행/446대, 전부 2026-08~09): **AS 접수만** (미발송 — W는 배정 정보일 뿐. 메디인 리허설서 검증됨)
   - X=빈값(8행/21대): 수동 확인
   - 완료인데 V 없음(42행): 일자 폴백 **V → N입고날짜 → A접수일**
   - 모순(미완료+V있음, 2행): 미완료 우선(진행중 유지)
2. **시리얼 없는 행 66행(199대 상당, 2025-05~06 집중)은 마이그 제외** (기기 단위 이벤트 불가 — 이력 유실 감수)
3. **병원 간 이동 357건**: 269건은 회수→재투입(정상, 시스템 흐름 그대로) / **88건 ACTIVE 충돌은 절충안**:
   - 앞 병원의 회수(F) 기록이 뒤늦게라도 존재하면 **날짜 재정렬로 자동 해소** (예: P002068 — 부산 투입 10-10보다 대구수성 회수 기재가 10-14로 늦음)
   - 잔여(진짜 오입력 의심: P001245 광주 2건, P002393 나은병원 등)만 **수동 확인 목록** 출력
4. **오입력 자동 보정 3종** (F↔W 불일치 44행·수량 불일치 38행 대부분 해소):
   - 셀 내 `A -> B(변경)` 표기 → 최종값(B) 채택
   - 심전도 A접두 누락(F열 `80316` ↔ W열 `A080316`) → W열 대조로 복원
   - W열 꼬리 추가 발송분(F보다 많음) → 수리 반환 + 신규 제공으로 분리
   - 그 외(행 간 분할 기재 33·38행, '시리얼 확인 불가' 330행 등)는 **행별 보정 시트**(엑셀 행번호+확정 F↔W 쌍) 우선 적용 레이어로
5. **병원별 단계 적용**: 초기 임포트 완료 병원부터 → **초기必 시리얼 검증 게이트**(이력에 F로 처음 등장하는 시리얼이 원장에 있는지 — 메디인 35/35 통과로 방법론 검증됨) → 통과 시 그 병원 이력 replay (dev2 리허설 → PROD)
