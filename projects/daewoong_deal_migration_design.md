## 2. 필드 분류 (엑셀 B~AK)

### 공통 축 — 엑셀로 채움 (규모·계약 영역 유지)
판매모델 2관점(F·G), 계약일(T), 최초 인입일(R), 보증기간(J), 도입병동(K), 도입진료과(L), 병동수(M), 병상수(N), 비고(AF)
- 차수: 병원 내 원장 순서로 발번 · 확장(I)은 차수≥2 파생 표시 (저장 안 함)
- 딜 상태: 블록 파생 — 최상단·도입확정 → `계약완료` / 취소병원 → `해지·중단`
- 단계(C)·종별(E)·답사(S)·납품일(U)·공사(V·W)·교육일(X)·공사지연일(Y)·오더현황(Z)·지역(AK): 기존대로 운영 축 조인 (저장 안 함)

### 대웅 축 — 신규 '대웅제약' 카드 (기존 '대웅 영업조직' 카드 대체)
| 엑셀 | 컬럼 | 처리 |
|---|---|---|
| 제품(구성품) O | `daewoong_amount_product` | **신설** (BIGINT) |
| 공사비 P | `daewoong_amount_construction` | **신설** (BIGINT) |
| 판매 Q | — | 파생 (대웅 제품+공사) |
| 용역매출 AB | `amount_service` → `daewoong_amount_service` | **개명** (어제 신설, 전 환경 0행 — 안전) |
| 판매가 AE | `price_type_text` → `daewoong_price_type` | **개명** (동일) |
| 사업부~연락처 AG~AJ | `daewoong_division/office/manager/phone` | 유지 (카드만 이동) |

### 씨어스 축 — 엑셀로 채우지 않음 (수기 입력용으로 비움)
`amount_product`(제품가) · `amount_construction`(공사비) — "기존에 우리가 관리하던 가격" 자리. 백필·이관으로 들어가 있던 대웅 값은 재적재로 자연 소거.

### 결정 필요 (§6)
실판매액(AC)·세금계산서(AD)·정산(AA)의 귀속 축 / 엑셀에 없는 기존 딜 21건 처리 / 대시보드 '판매' 지표 기준 / 덕천부민병원 매핑
